# InstantesEternos — Guía de fotografía desde cero
Autor: Alberto Benjamin Poot Veloz

Sitio informativo estático (HTML + CSS + JavaScript, sin dependencias).

## Estructura
```
index.html        contenido de la página
styles.css        estilos (claro/oscuro y responsive)
main.js           menú, carga de fotos, tablas móviles y modo oscuro
images/           fotos (nombres exactos indicados en index.html)
```
